# Sécurité

## Signaler une faille

Merci de **ne pas** ouvrir de ticket public pour une faille de sécurité. Utilisez le signalement privé de GitHub :
onglet **Security › Report a vulnerability** de ce dépôt. Décrivez ce que vous avez trouvé et comment le reproduire ;
nous répondons au plus vite et corrigeons avant toute publication.

## Ce qui est considéré comme une faille

Accès aux sons ou aux données d'un serveur Discord dont on n'est pas membre, contournement des droits (admin,
envoi, blocage), fuite du jeton ou des sessions, exécution de code côté serveur ou client.

Le jeton partagé de l'instance publique est **volontairement** embarqué dans le client (voir `README.md`) : ce
n'est pas, en soi, une faille.
