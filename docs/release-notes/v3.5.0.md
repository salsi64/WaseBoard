## WaseBoard 3.5.0 — Vos catégories personnelles sur le web et dans l'Activité

Mise à jour compatible : l'ancienne version continue de fonctionner avec le nouveau serveur ; la nouveauté ci-dessous demande cette version de l'application **et** un serveur à jour.
*English summary at the bottom.*

### Nouveau

- **📁 Vos catégories personnelles sur la version web et dans l'Activité Discord** : les catégories que vous créez dans l'application Windows apparaissent maintenant aussi dans la page web (`/app/`) et dans l'Activité, sous forme d'onglets et de sections, dans le même ordre que dans l'application (mêlées aux serveurs).
- L'application en envoie une copie au serveur quelques secondes après chaque modification et au lancement. Cette copie ne contient que le nom de vos catégories et les identifiants de leurs sons ; elle n'est visible que de vous, et supprimée dès que vous n'avez plus de catégories (voir la [politique de confidentialité](https://waseboard.salsi.bid/privacy.html)).
- C'est l'application Windows qui reste la source : la page web affiche vos catégories mais ne les modifie pas. Avec deux PC, c'est le dernier envoi qui est affiché.
- La page web relit le catalogue en revenant au premier plan après une minute d'inactivité, et l'onglet choisi reste visible quand il y en a beaucoup.

### Pour les personnes qui hébergent

- Nouvelle route `GET`/`PUT /me/categories`, annoncée par `/status` (fonction `personal_categories`) ; données dans `user_categories.json` (droits 600), incluses dans `backup.sh`.

### English summary

Your **personal categories** (the ones you create in the Windows app) now also show up in the **web version** and the **Discord Activity**, as tabs and sections in the same order as in the app. The app sends a copy to the server a few seconds after each change; it only holds category names and sound IDs, is visible to you alone, and is deleted when you have no categories left. The Windows app stays the source: the web page displays them but doesn't edit them. Needs this app version and an up-to-date server.
