Politique de confidentialité

Dernière mise à jour : 4 octobre 2026

WaseBoard est un soundboard partagé pour Discord. Cette page décrit les données traitées par l'instance publique par défaut (waseboard.salsi.bid) et le bot Discord associé. WaseBoard étant open-source, n'importe qui peut héberger sa propre instance : si vous utilisez celle d'un tiers, contactez cette personne — elle seule contrôle ses propres données.

Données collectées

  • Identité Discord : via la connexion OAuth2 Discord, nous recevons votre identifiant Discord, votre pseudo et l'URL de votre avatar. Jamais votre e-mail ni votre mot de passe.
  • Présence vocale : pour savoir dans quel salon vocal vous rejoindre, le bot observe en temps réel votre présence sur les salons des serveurs où il est présent — non conservée au-delà de cet usage immédiat.
  • Appartenance aux serveurs : la liste des serveurs Discord que vous partagez avec le bot, pour déterminer quels sons vous sont accessibles.
  • Sons que vous ajoutez : les fichiers audio importés sont stockés sur le serveur, associés au serveur Discord concerné et à votre identifiant (auteur), pour la gestion (suppression, corbeille).
  • Statistiques d'usage : quel son a été joué, par qui, et quand — visible par les administrateurs du serveur concerné dans son panel d'administration.
  • Journal d'actions admin : les actions des administrateurs (réglages, suppression de son...) sont journalisées avec leur identifiant, pour traçabilité.
  • Jetons de session : pour éviter de vous reconnecter en permanence, un jeton de session interne et le jeton d'accès Discord associé sont stockés côté serveur, chiffrés.

Ce que nous ne faisons pas

  • Nous n'enregistrons jamais votre micro ni le contenu audio de vos salons vocaux — WaseBoard joue des sons, il n'écoute rien.
  • Nous ne revendons ni ne partageons vos données avec des tiers.
  • Aucune publicité, aucun tracker, aucune analyse comportementale.

Qui a accès à mes données ?

Les membres d'un salon vocal voient votre pseudo/avatar quand vous jouez un son, comme sur Discord normalement. Les administrateurs du panel d'un serveur voient les statistiques d'usage et le journal d'actions de ce serveur uniquement (isolation stricte entre serveurs). La personne qui héberge l'instance (pour l'instance publique par défaut : le mainteneur du projet) a un accès technique aux données stockées sur son propre serveur.

Suppression de vos données

Un administrateur de votre serveur peut supprimer vos sons depuis le panel (avec corbeille temporaire avant suppression définitive). Pour toute autre demande, contactez-nous sur le Discord WaseBoard.

Code source

WaseBoard est open-source : github.com/salsi64/WaseBoard — vous pouvez vérifier vous-même exactement quelles données sont traitées, et héberger votre propre instance si vous préférez garder un contrôle total sur les vôtres.
