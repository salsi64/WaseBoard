WaseBoard

Soundboard partagé pour Discord — cliquez un son, il joue à la fois sur vos enceintes et dans le vocal, pour tout le monde, sans jamais passer par votre micro.
⬇ Télécharger le client Windows 💬 Rejoindre le Discord WaseBoard

Comment ça marche

Cette page est le point d'accès d'une instance de WaseBoard : une application Windows (le client, que vous installez) qui se connecte à un serveur hébergeant le catalogue de sons partagé et un bot Discord. Quand vous cliquez un son, il joue en même temps sur vos propres enceintes et par le bot dans votre salon vocal.

Rejoindre un serveur existant

Si quelqu'un vous a invité sur son serveur WaseBoard :

  1. Installer le client (bouton ci-dessus).
  2. Ouvrir le lien de connexion reçu sur Discord (bouton « Ouvrir WaseBoard ») — l'application se configure toute seule. Sans lien, l'adresse du serveur se saisit à la main dans les Paramètres.
  3. Se connecter avec votre compte Discord quand l'application le demande : ça sert uniquement à afficher votre avatar et à retrouver votre salon vocal, rien d'autre à saisir.

Héberger votre propre serveur

WaseBoard est open-source et fait pour être auto-hébergé : chaque groupe héberge sa propre instance, il n'y a pas de serveur central fourni avec le projet.

Le plus simple : git clone le dépôt, puis lancer l'assistant Docker (./setup.sh ou .\setup.ps1) — il vous guide pour créer l'application bot Discord, vérifie la configuration et démarre tout, en une quinzaine de minutes.

Guide complet (installation Docker ou manuelle, HTTPS, sécurité, dépannage) : server/README.md sur le dépôt GitHub.
